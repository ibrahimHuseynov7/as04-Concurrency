## Image Pixelation

Divides an image into `square_size × square_size` blocks and fills every block
with its average color. Supports a single-threaded and a multi-core mode.

Work in progress.

## Installation

**macOS / Linux**
Create virtual environment if you have version conflicts


```bash
python3 -m venv .venv 
source .venv/bin/activate
pip install -r requirements.txt
```

**Windows**

```bat
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
